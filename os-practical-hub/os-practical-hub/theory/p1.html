This practical builds a small menu-driven address book using a shell script. Each contact is stored as one line in a plain text file.

Key concepts

  • Shell – a program (here bash) that reads commands typed by the user or from a file and asks the operating system to run them.
  • Shell script – a text file containing shell commands. The first line #!/bin/bash (the shebang) tells the system which interpreter should run it. Make it executable with chmod +x.
  • Functions – create_book, view_book, insert_record, delete_record and modify_record each handle one menu option, keeping the script organised.
  • read -p – prints a prompt and stores what the user types in a variable.
  • case … esac – chooses which function to run depending on the menu letter entered. ${ch,,} converts the choice to lower case.
  • Redirection – > overwrites a file (: > "$FILE" creates an empty one) and >> appends a new line to it.

Tools used for the records

  • grep – searches for a pattern. grep -q "^$id|" checks silently whether a line starts with the given ID; grep -v prints all lines that do not match, which is how a record is deleted.
  • awk – processes text field by field. With -F'|' the | character separates the fields (ID, name, phone, email). It is used both to print the table and to rewrite one record when modifying.
  • mv – replaces the address book with the edited temporary file.

Record format

One contact per line: ID|Name|Phone|Email. The ID acts like a primary key – the script refuses to insert a duplicate ID.
