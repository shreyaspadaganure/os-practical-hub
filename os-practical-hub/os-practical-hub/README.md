# OS Practical Hub

Operating System Practical Programs – a static website (plain HTML, CSS, JavaScript) with 8 OS lab practicals.
Each practical page shows **Theory → Code → Output**.

## Publish permanently with GitHub Pages
1. Create a new **public** repository on GitHub (e.g. `os-practical-hub`).
2. Upload **everything in this folder** (keep the folder structure; `index.html` must be at the top level).
3. Repository **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder = `/ (root)`, then **Save**.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

## Folder layout
| Path | Purpose |
|---|---|
| `index.html`, `practical-1.html` … `practical-8.html` | The pages (generated by `build.py`) |
| `code/` | Source code of each practical (edit here) |
| `theory/` | Theory text of each practical, as small HTML snippets (edit here) |
| `assets/img/` | Output screenshots extracted unchanged from the PDF |
| `assets/css`, `assets/js` | Styling, syntax-highlight colours, Copy Code button |
| `build.py` | Regenerates the pages (`pip install pygments`, then `python3 build.py`) |

## Updating
- Change code: edit the file in `code/`, run `python3 build.py`, upload the changed files.
- Change a screenshot: replace `assets/img/practical-N-output.png` (same name).
- Add the missing Process 2 code (Practical 6): put it in `code/` and extend the `PRACTICALS` entry in `build.py`.

## Notes on the source PDF
- **Practical 6:** the PDF has only Process 1 (`fifo1.c`). The Process 2 code (`fifo2.c`) is missing; its run appears in the screenshot only.
- **Practical 1:** the PDF's text had its `$` variables damaged (shown as math symbols, e.g. `"𝐹𝐼𝐿𝐸"`). They were restored to `$FILE`, `$id`, `$name`, `$phone`, `$email` – tested; behaviour matches the screenshot.
- **Practicals 4, 5, 6:** the PDF had lost its line breaks; code was re-split into lines. Only whitespace changed – tokens were verified identical to the PDF.
- Long lines that the PDF wrapped in the middle of a string were rejoined so the code compiles.
